# Visual provenance

No third-party photographs, stock images, screenshots, fonts, icon libraries, or externally sourced image assets are used by this website.

The project visual assets in `assets/` are original SVG artwork created specifically for this public AASP project showcase:

- `assets/hero-audio.svg` — original conceptual audio-field illustration; public showcase use only.
- `assets/favicon.svg` — original project favicon.

The hero image is explicitly presented as a conceptual visualization and is not represented as a screenshot of the private application runtime.
