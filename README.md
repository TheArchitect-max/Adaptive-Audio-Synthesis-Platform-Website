# Adaptive Audio Synthesis Platform — Website

Public GitHub Pages showcase for **Adaptive Audio Synthesis Platform (AASP)**, an independent project by TheArchitectMax.

This repository intentionally contains presentation assets only: static HTML, CSS, minimal client-side JavaScript, and original SVG artwork. The underlying AASP software remains private/proprietary and is not mirrored here.

## Local preview

Open `index.html` directly in a browser, or serve the directory with any simple static-file server.

## Public boundary

This website does not contain application credentials, private source code, model weights, internal schemas, private API configuration, deployment secrets, or proprietary implementation detail.

## GitHub Pages

Publish from the repository's `main` branch root using GitHub Pages. No GitHub Actions workflow is required for the static site.
